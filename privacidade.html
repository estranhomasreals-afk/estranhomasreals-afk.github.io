Meus Canais Publisher - Política de Privacidade

Última atualização: 26 de novembro de 2026

1. Quem usa o aplicativo

O Meus Canais Publisher é uma ferramenta pessoal para computador, usada apenas pelo seu dono para publicar vídeos nas suas próprias contas do TikTok.

2. Dados acessados

Quando o dono autoriza uma conta do TikTok, o aplicativo recebe:

  • Informações básicas do perfil (nome de exibição, foto e identificador da conta), para mostrar qual conta está conectada.
  • Um token de acesso, que permite enviar e publicar vídeos nessa conta.

3. Como os dados são usados

Esses dados são usados apenas para publicar os vídeos do dono na conta conectada. Eles não são vendidos, compartilhados nem usados para publicidade.

4. Onde os dados ficam

Os tokens de acesso ficam no computador do dono e são usados apenas pela ferramenta de publicação dele. Os dados nunca são vendidos nem compartilhados para outra finalidade.

5. Como remover o acesso

O acesso pode ser removido a qualquer momento, desconectando a conta no aplicativo ou nas configurações do TikTok (Segurança > Gerenciar permissões de apps). Os tokens guardados são então apagados.
